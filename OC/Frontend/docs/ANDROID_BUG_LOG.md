## Leyenda de severidad

- **S1 Critico:** bloquea login, sesion, reserva o uso basico.
- **S2 Alto:** funcionalidad clave degradada con workaround parcial.
- **S3 Medio:** falla no bloqueante con impacto UX relevante.
- **S4 Bajo:** detalle visual/texto/comportamiento menor.
