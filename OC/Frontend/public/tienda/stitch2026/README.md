# OC-STORE: fotografías editoriales 2026

Las fotografías `equipamiento-stitch.webp`, `suplementos-stitch.webp`,
`ropa-stitch.webp` y `recovery-stitch.webp` son imágenes conceptuales
originales generadas para el nuevo lenguaje visual de OC-STORE.

No representan artículos disponibles confirmados, marcas de terceros,
instalaciones del gimnasio ni los productos específicos del catálogo.

Referencia visual aportada por el cliente:
- `stitch_oc_club_ui_ux_redesign (2).zip`
- `code.html`, `DESIGN.md`, `screen.png`

El ZIP de Stitch **no incluía fotografías exportadas**: su HTML apuntaba
a URLs externas de Google. Por estabilidad y licencia, no se enlazaron
externamente ni se copiaron imágenes de baja resolución desde la captura.

Estas imágenes se guardan como recursos nuevos independientes, sin
sustituir ni borrar los PNG/JPEG originales ya presentes en
`public/tienda/imagenes`.

El catálogo, precios, variantes, carrito, checkout asistido y páginas de
productos conservan su propio modelo actual y **no se sustituyeron**
por los artículos/precios ficticios del prototipo Stitch.

Para publicar las fotografías exactas del prototipo, será necesario
exportar sus archivos originales por separado.
